📱 Manual Testing Steps

1. PWA Installation Test

Desktop (Chrome/Edge):

  1. Go to: http://127.0.0.1:3000
  2. Look for install prompt at bottom of screen
  3. Click "Install" button
  4. App should open in standalone mode

Mobile (Android Chrome):

  1. Open in mobile Chrome browser
  2. Tap menu → "Add to Home screen"
  3. App icon should appear on home screen
  4. Tap icon to open in standalone mode

2. Offline Functionality Test

  1. Install the PWA first
  2. Open Chrome DevTools (F12)
  3. Go to Network tab
  4. Check "Offline" checkbox
  5. Refresh the page
  6. Should show offline page, not browser error

3. Service Worker Test

  1. Open Chrome DevTools (F12)
  2. Go to Application tab
  3. Click "Service Workers"
  4. Should see "activated and running" status
  5. Check console for registration messages

4. Manifest Test

  1. Open Chrome DevTools (F12)
  2. Go to Application tab
  3. Click "Manifest"
  4. Should see app details and icons
  5. No errors should be shown
